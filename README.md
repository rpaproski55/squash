# Squash

A guidance-first progress app for squash players: what to work on today, and
evidence that you are improving. Phone-first, offline, data on the device.

See `docs/PRODUCT_BRIEF.md` for the product decisions and build order.

## Run it

```
npm install
npm run dev      # local dev server
npm test         # logic and scene tests
npm run build    # static build in dist/
```

## Source

Level structure and lesson ideas from the
[SquashClub.org e-Lessons](https://www.squashclub.org/main/e-lessons/),
rewritten in our own words. The original reference page is kept at
`docs/reference-ladder.html`.
