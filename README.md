# Squash Level Ladder

A visual squash level-progression reference, built from the
[SquashClub.org e-Lessons](https://www.squashclub.org/main/e-lessons/)
level guide (recommended by Mauricio).

## What it is now

`index.html` is a single-file static page: every rung from 2.0 (E) to 6.0 (Pro)
as a card, with the fundamentals to own at that level, the shots it unlocks,
the classic trap to avoid, and a drill from the source lesson. Current level
**3.5 (C)** is marked as "You are here", with 4.0 (C+) as the next rung.
Fundamentals are tappable to mark Solid / Working on it / Missing, with a
live tally for a quick gap check. It also includes the four ingredients of a
correct hit, a court diagram (good length, the T), and the Ten Commandments
as a permanent checklist.

Open `index.html` in a browser to use it.

## Where it's going: the app

The plan is to grow this into a real app:

1. **Track progress** — persist Solid / Working on it / Missing per
   fundamental, per level, with history over time so progress is visible.
2. **Level focus** — a clear "what to work on at your level" view, with the
   next steps from 3.5 toward 4.0 spelled out.
3. **Session-based visuals** — pick the time available and the session type
   (solo drills, match play, round robin) and get the visuals and drills
   relevant to that session.
